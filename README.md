# RaceDay System - Project Documentation & Setup

Welcome to the **RaceDay** system repository. This repository contains all planning documentation, database schemas, and configuration scripts required for Part 1 of the project.

## Repository Structure (`/docs`)

All planning artifacts are located inside the `docs/` folder:
* **ERD (Entity-Relationship Diagram):** Visual model mapping the 6 core system entities (`Users`, `Events`, `Categories`, `Enrolments`, `Results`, `Payments`).
* **API Endpoint Plan:** Detailed route planning table covering authentication, user profiles, events, categories, enrolments, and results.
* **SQL Database Script:** Full database creation and seed script (`.sql`).

---

## Database Setup Instructions

1. Open **SQL Server Management Studio (SSMS)**.
2. Open the `.sql` script located in the `/docs` folder.
3. Execute the script to automatically build the `RaceDay` database, create all 6 tables with proper constraints, and seed the required sample data (organisers, participants, events, categories, enrolments, payments, and results).
